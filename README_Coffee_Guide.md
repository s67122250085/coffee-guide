# Coffee Guide

เว็บไซต์ **Coffee Guide** เป็นเว็บแอปพลิเคชันสำหรับแนะนำข้อมูลเกี่ยวกับพันธุ์กาแฟและเมนูกาแฟ โดยจัดเตรียมข้อมูลและ Digital Assets ให้สามารถนำไปใช้ในการพัฒนา User Interface และต่อยอดไปสู่การออกแบบฐานข้อมูลได้อย่างเป็นระบบ

## 1. โครงสร้าง Dataset

Master Dataset หลักถูกจัดเก็บไว้ใน `data/data.js` และมีข้อมูล 2 กลุ่ม ได้แก่

### Coffee Varietals

ข้อมูลพันธุ์กาแฟจำนวน **10 รายการ**

| Field | รายละเอียด |
|---|---|
| `coffee_id` | รหัสข้อมูลพันธุ์กาแฟ เช่น C001 |
| `name_th` | ชื่อพันธุ์กาแฟภาษาไทย |
| `name_en` | ชื่อพันธุ์กาแฟภาษาอังกฤษ |
| `type` | ประเภทกาแฟ เช่น Arabica, Robusta |
| `description` | รายละเอียดของพันธุ์กาแฟ |
| `province` | จังหวัดหรือพื้นที่ปลูก |
| `flavor` | ลักษณะรสชาติ |
| `source` | แหล่งข้อมูล |
| `image` | ชื่อไฟล์รูปภาพ |
| `tag` | Tag / Keyword สำหรับการค้นหา |

รายการรหัสข้อมูล: `C001–C010`

### Coffee Menu

ข้อมูลเมนูกาแฟจำนวน **20 รายการ**

| Field | รายละเอียด |
|---|---|
| `menu_id` | รหัสเมนู เช่น M001 |
| `name_th` | ชื่อเมนูภาษาไทย |
| `name_en` | ชื่อเมนูภาษาอังกฤษ |
| `flavor` | ลักษณะรสชาติ |
| `source` | แหล่งข้อมูล |
| `image` | ชื่อไฟล์รูปภาพ |
| `tag` | Tag / Keyword สำหรับการค้นหา |

รายการรหัสข้อมูล: `M001–M020`

### จำนวนข้อมูลทั้งหมด

- Coffee Varietals: **10 รายการ**
- Coffee Menu: **20 รายการ**
- รวมทั้งหมด: **30 รายการ**

## 2. Data Requirement Analysis

| Function / Feature | ข้อมูลที่ต้องใช้ | แหล่งข้อมูล | รูปแบบข้อมูล |
|---|---|---|---|
| แสดงรายการพันธุ์กาแฟ | ชื่อพันธุ์, ประเภท, รูปภาพ, Tag | แหล่งข้อมูลพันธุ์กาแฟ / Dataset | Text, Image |
| แสดงรายละเอียดพันธุ์กาแฟ | ชื่อ, รายละเอียด, จังหวัด, รสชาติ, แหล่งข้อมูล, รูปภาพ | งานวิจัย / หน่วยงานด้านกาแฟ / Dataset | Text, Image |
| แสดงรายการเมนูกาแฟ | ชื่อเมนู, รูปภาพ, Tag | เว็บไซต์และแหล่งข้อมูลเกี่ยวกับกาแฟ | Text, Image |
| แสดงรายละเอียดเมนู | ชื่อเมนู, รสชาติ, แหล่งข้อมูล, รูปภาพ | เว็บไซต์ร้านกาแฟ / แหล่งข้อมูลเมนู | Text, Image |
| ค้นหา | ชื่อพันธุ์, ชื่อเมนู, ประเภท, รสชาติ, Tag | Dataset | Text |

ข้อมูลทั้งหมดถูกออกแบบให้สัมพันธ์กับฟังก์ชันของเว็บ เช่น การแสดง Card, หน้ารายละเอียด และการค้นหาข้อมูล

## 4. มาตรฐานการตั้งชื่อไฟล์

กำหนดชื่อไฟล์โดยใช้รหัสเดียวกับข้อมูลใน Dataset เพื่อให้สามารถเชื่อมโยงระหว่างข้อมูลกับรูปภาพได้ง่าย

### รูปพันธุ์กาแฟ

รูปแบบ:

```text
C001.webp
C002.webp
...
C010.webp
```

### รูปเมนูกาแฟ

รูปแบบ:

```text
M001.webp
M002.webp
...
M020.webp
```

### Logo

```text
LOGO.png
```

หลักการตั้งชื่อ:
- ใช้รหัสข้อมูลเป็นชื่อไฟล์
- ใช้ตัวพิมพ์ใหญ่สำหรับรหัส `C` และ `M`
- ใช้นามสกุล `.webp` สำหรับภาพข้อมูล
- ใช้ `.png` สำหรับ Logo
- หลีกเลี่ยงชื่อไฟล์ทั่วไป เช่น `IMG_1234.jpg` หรือ `picture1.jpg`

## 7. แหล่งที่มาของข้อมูลและ Digital Assets

ข้อมูลและภาพถูกจัดทำโดยอ้างอิงจากหลายแหล่งตามที่ระบุไว้ในเอกสารประกอบโครงการ เช่น

- World Coffee Research
- กรมวิชาการเกษตร
- สถาบันวิจัยและพัฒนาพื้นที่สูง (HRDI)
- เว็บไซต์และแหล่งข้อมูลของร้านกาแฟ
- แหล่งข้อมูลเกี่ยวกับเมนูกาแฟ
- ภาพที่จัดทำขึ้นเองโดยผู้จัดทำ

รายละเอียด URL/Reference และ License/Permission ของแต่ละไฟล์ถูกรวบรวมไว้ในเอกสาร `documents/Coffee Guide.pdf`

> หมายเหตุ: ควรตรวจสอบสิทธิ์การใช้งานและเงื่อนไขของภาพจากต้นทางก่อนนำเว็บไซต์ไปเผยแพร่จริง

## 8. ข้อจำกัดหรือปัญหาที่พบ

1. ใน Dataset `data.js` ช่อง `image` ของข้อมูลพันธุ์กาแฟและเมนูยังระบุเป็น `"-"` ทั้งที่มีไฟล์ภาพจริงอยู่ในโฟลเดอร์ `images/` ดังนั้นก่อนนำไปใช้จริงควรเชื่อมค่า `image` ให้ตรงกับชื่อไฟล์ เช่น `C001.webp` หรือ `M001.webp`
2. แหล่งข้อมูลใน Dataset บางรายการอาจไม่ตรงกับ Source ที่ระบุในเอกสาร Data and Asset Sources จึงควรตรวจสอบและทำให้เป็นมาตรฐานเดียวกันก่อนนำไปสร้างฐานข้อมูล
3. รูปภาพมีมาตรฐานขนาดแตกต่างกันตามประเภทของ Asset ได้แก่ Coffee Varietals 360 × 360 px และ Coffee Menu 200 × 200 px ซึ่งต้องกำหนดให้ชัดเจนในส่วนของ UI เพื่อป้องกันการแสดงผลไม่สม่ำเสมอ
4. เอกสารระบุชื่อไฟล์ Logo เป็น `LOGO.peg` ในบางส่วน แต่ไฟล์จริงในโครงสร้างโครงการคือ `LOGO.png` จึงควรใช้ `LOGO.png` เป็นมาตรฐาน
5. แหล่งข้อมูลภาพจากเว็บไซต์ภายนอกบางรายการควรตรวจสอบ URL และ License/Permission อีกครั้งก่อนเผยแพร่โครงการ

## 9. สรุป

Coffee Guide มี Master Dataset จำนวน **30 รายการ** แบ่งเป็นพันธุ์กาแฟ 10 รายการ และเมนูกาแฟ 20 รายการ พร้อม Digital Assets จำนวน **31 ไฟล์** ประกอบด้วยภาพพันธุ์กาแฟ 10 ภาพ ภาพเมนูกาแฟ 20 ภาพ และ Logo 1 ภาพ

โครงสร้างข้อมูล การตั้งชื่อไฟล์ และการจัดเก็บ Folder ถูกกำหนดให้สามารถเชื่อมโยงข้อมูลกับ Digital Assets ได้ง่าย และสามารถนำไปใช้ต่อในขั้นตอนการออกแบบฐานข้อมูลและพัฒนาเว็บแอปพลิเคชันได้
